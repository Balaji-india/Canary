---
description: "Run the research-question evaluations and interpret them honestly"
argument-hint: "[rq number(s) or 'all']"
---
Run evaluation: $ARGUMENTS (default: every RQ whose code exists).

Use the `eval/rq*.py` scripts; they write `eval/results/*.json` and figures. Record model tags, seeds and run counts.
Then explain each result in plain words, with intervals; say what it does and doesn't show, and whether the sample
is big enough. Never type numbers by hand.
